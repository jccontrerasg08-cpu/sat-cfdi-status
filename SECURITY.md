# Política de seguridad

## Reportar una vulnerabilidad

No publiques vulnerabilidades, XML, RFC, UUID, sellos ni Acuses en issues públicos. Usa una [advisory privada de GitHub](https://github.com/jccontrerasg08-cpu/sat-cfdi-status/security/advisories/new) e incluye pasos de reproducción mínimos sin datos fiscales reales.

## Alcance

Se reciben reportes sobre la aplicación web, el proxy SOAP, la configuración de Vercel y las dependencias del repositorio. El endpoint público del SAT no está bajo control de este proyecto.

Se confirmará la recepción y se evaluará el reporte antes de publicar una corrección. La información del reporte se tratará como confidencial hasta acordar una divulgación responsable.
