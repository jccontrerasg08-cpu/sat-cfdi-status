# Código de conducta

El proyecto busca una comunidad técnica respetuosa y accesible. Se espera comunicación profesional, crítica constructiva y respeto por la privacidad de la información fiscal.

No se toleran acoso, discriminación, exposición de datos personales o fiscales, ni ataques personales. Para informar una conducta contraria, usa una [advisory privada de GitHub](https://github.com/jccontrerasg08-cpu/sat-cfdi-status/security/advisories/new).
